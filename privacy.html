ContextFlow 隐私政策

更新日期：2026年10月23日。说明 Chrome 扩展、可选的本地服务及桌面客户端的数据处理方式。当前 Mac ARM64 安装包为独立分发，未使用 Developer ID 签名、未通过 Apple 公证。各项能力、连接要求与系统限制以客户端下载说明为准。

用途与处理的数据

ContextFlow 帮助你在网页阅读时保存高亮、批注、问题、翻译和总结，并将记录同步到你自己的笔记库。它会处理正在使用功能的网页 URL、标题、选区、正文、图片、批注、问题和 AI 回答。配置同步或本地 agent 后，还可能处理你选择的笔记路径及授权范围内的笔记内容。

扩展在普通 HTTP/HTTPS 网页上运行以恢复已有批注，并提供阅读界面。AI、笔记同步和 agent 能力通过你自己的本地服务执行；不提供由开发者集中收集阅读记录的云端账号服务。

保存位置

  • 离线批注、图片和待同步操作保存在扩展所属的 IndexedDB，不写入普通网页所属的 localStorage 或 IndexedDB。
  • 站点偏好和配对凭证保存在扩展本机存储，不使用 Chrome 同步存储。配对凭证仅供受信任的扩展上下文使用。
  • 本地服务的数据库、模型配置、API key 和 agent 配置保存在你电脑上的 ContextFlow 配置目录；同步输出保存在你选择的笔记目录或笔记服务。
  • 桌面端另外保存启动偏好、独立浏览器授权、后台服务日志及可选的本机恢复点。桌面端保存的模型密钥、思源 token 和 Agent 环境凭据会加密，主密钥由系统凭据保护；阅读数据库、图片、导出的文件和原始日志本身不宣称加密。
  • 连接测试、真实回答和同步状态保留有界的摘要标识、结果与时间，用于区分已安装、已测试、实际回答及实际写入；这些状态收据不保存文章、问题、回答、网址、原始笔记路径或密钥。

阅读库与备份

支持阅读库的版本可在扩展自己的页面中检索已保存在此扩展内的跨网站阅读记录，不需要账号或本地服务。完整阅读库和备份恢复接口不向普通网页开放，也不会为此读取浏览器历史或新增标签访问权限。

你可主动生成包含有效记录、历史回答及引用图片的 JSON 备份，或下载单篇 Markdown。备份不包含模型配置、API key、配对码、缓存网页全文或只存在于本地服务的记录；备份文件可读且未加密，保存和分享由你控制。恢复前会校验并展示内容，确认后只补充缺失记录，不覆盖现有内容或已删除记录，也不重启未完成的 AI 任务。恢复的记录在阅读页面按原有规则保存到已连接的本地服务，写入笔记软件仍需主动同步。

桌面端的「本机恢复点」是另一种本地保护方式，包含服务数据库、附件、配置与受系统保护的密钥，只适用于原电脑的系统账号；不包含扩展中尚未发送的记录、外部笔记文件或浏览器授权，也不会恢复已撤销授权。恢复点中的阅读内容未加密，不应公开分享；既有恢复点不会因卸载扩展而自动删除。

何时数据会离开电脑

“本地优先”不等于所有 AI 请求离线执行。使用翻译、解释、总结或本地 agent 时，相关网页内容、问题、对话以及授权读取的笔记可能发送到你配置的模型、网关、agent 或 MCP 服务。打开或恢复侧栏只读取已有结果，主动生成或重试才会发送文章内容。主动点击连接测试时只发送固定短消息，不发送文章或笔记。是否调用外部服务及其处理方式取决于你的配置。

你可以主动在扩展「帮助与诊断」检查本地服务健康状态和扩展存储计数，不会调用 AI 或上传报告。扩展诊断包含版本、连接状态、能力与记录 / 图片 / 待发送操作数量；桌面端的脱敏诊断还包含系统类型、架构、浏览器连接和任务数量、后台入口状态。两者均不包含文章、网址、笔记、密钥、配对码、模型地址、文件路径或完整日志。报告由你主动复制或导出，自行决定是否发送给维护者。通过桌面端打开的原始日志不属于脱敏报告，可能含个人信息，请勿直接公开。

桌面端使用手动更新，不在后台自动下载或安装新版本；从官网下载匹配安装包，在任务空闲后退出正在运行的应用再覆盖安装，保留配置和阅读数据。Chrome 扩展仍通过商店更新。官网由 GitHub Pages 托管，访问官网或 GitHub 下载、反馈页面会向 GitHub 发送普通网络访问信息，受其隐私声明约束；官网不接收扩展内的阅读记录、模型密钥或配对凭据。

这些服务按其自身条款和隐私政策处理数据。请在启用前确认其数据保留、训练使用和地域等安排，避免向不合适的服务发送机密资料。外部模型接口应配置 HTTPS；扩展到本机服务使用经过配对认证的回环 HTTP 连接。

本地 agent 与授权

扩展在用户主动操作并确认后，通过 Chrome Native Messaging 与本机 ContextFlow 桌面应用完成配对。桥接用于本机连接授权，不是任意命令接口；各浏览器安装实例分别授权，可在桌面端单独撤销。桌面端管理的模型密钥和 Agent 环境凭据使用系统凭据保护支持的本地加密保存，不会回传明文到阅读页面。

桌面端自动发现仅检查支持的 Agent 安装信息和 Obsidian 已登记库的路径，不读取笔记正文，不全盘扫描，不替用户登录或调用模型。菜单栏可见性检查只读取本机屏幕几何，不截屏、不读取其他应用窗口内容，也不为此请求录屏或辅助功能权限。

笔记读取目录由你明确选择。本地 agent 默认使用受限配置；开启高级完整权限前需要单独确认风险。完整权限可能允许文件写入、命令执行、网络访问及 MCP 操作，网页或笔记中的不可信指令可能影响 agent 行为。

数据用途与共享

数据仅用于提供和维护你选择的阅读、AI 与笔记同步功能。当前扩展不加入广告、使用统计遥测或开发者运营的远程阅读数据采集。不出售用户数据，不将用户数据用于个性化广告、信用评估或与单一用途无关的目的。向你配置的服务传输数据仅为完成相应功能。

ContextFlow 对用户数据的处理遵循 Chrome Web Store 用户数据政策及 Limited Use 要求。

保留、删除与撤销

  • 你可以在界面中删除批注、导出 Markdown，或停止同步。删除源记录不意味着自动删除所有已导出的文件、备份或第三方留存副本。
  • 卸载扩展会删除扩展自身的浏览器存储，但不会删除本地服务数据库、同步笔记或第三方服务保留的数据。
  • 如需彻底删除本地服务数据，请先停止服务、备份需要保留的记录，再删除你自己的 ContextFlow 数据目录及选定的同步文件。不要删除整个笔记库来清理单个插件。
  • 扩展「连接与设置」中的「断开本扩展连接」只清除本扩展的连接凭据，不等于撤销服务端授权。桌面端用户可在「设置与帮助」→「浏览器授权」中单独撤销对应浏览器，不会因此删除阅读记录或笔记。
  • 关闭桌面窗口通常继续后台运行；选择「退出 ContextFlow」才会停止其服务。卸载桌面应用不等于删除服务数据库、系统账号中的配置、原始日志、本机恢复点或已写入的笔记，请按需单独清理并先备份。
