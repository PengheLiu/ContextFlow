ContextFlow 隐私政策

更新日期：2026年10月17日。适用于包含扩展私有存储和独立配对功能的 Chrome 扩展版本。

用途与处理的数据

ContextFlow 帮助你在网页阅读时保存高亮、批注、问题、翻译和总结，并将记录同步到你自己的笔记库。它会处理正在使用功能的网页 URL、标题、选区、正文、图片、批注、问题和 AI 回答。配置同步或本地 agent 后，还可能处理你选择的笔记路径及授权范围内的笔记内容。

扩展在普通 HTTP/HTTPS 网页上运行以恢复已有批注，并提供阅读界面。AI、笔记同步和 agent 能力通过你自己的本地服务执行；不提供由开发者集中收集阅读记录的云端账号服务。

保存位置

  • 离线批注、图片和待同步操作保存在扩展所属的 IndexedDB，不写入普通网页所属的 localStorage 或 IndexedDB。
  • 站点偏好和配对凭证保存在扩展本机存储，不使用 Chrome 同步存储。配对凭证仅供受信任的扩展上下文使用。
  • 本地服务的数据库、模型配置、API key 和 agent 配置保存在你电脑上的 ContextFlow 配置目录；同步输出保存在你选择的笔记目录或笔记服务。

何时数据会离开电脑

“本地优先”不等于所有 AI 请求离线执行。使用翻译、解释、总结或本地 agent 时，相关网页内容、问题、对话以及授权读取的笔记可能发送到你配置的模型、网关、agent 或 MCP 服务。展开阅读面板可能触发文章速览。是否调用外部服务及其处理方式取决于你的配置。

这些服务按其自身条款和隐私政策处理数据。请在启用前确认其数据保留、训练使用和地域等安排，避免向不合适的服务发送机密资料。外部模型接口应配置 HTTPS；扩展到本机服务使用经过配对认证的回环 HTTP 连接。

本地 agent 与授权

笔记读取目录由你明确选择。本地 agent 默认使用受限配置；开启高级完整权限前需要单独确认风险。完整权限可能允许文件写入、命令执行、网络访问及 MCP 操作，网页或笔记中的不可信指令可能影响 agent 行为。

数据用途与共享

数据仅用于提供和维护你选择的阅读、AI 与笔记同步功能。当前扩展不加入广告、使用统计遥测或开发者运营的远程阅读数据采集。不出售用户数据，不将用户数据用于个性化广告、信用评估或与单一用途无关的目的。向你配置的服务传输数据仅为完成相应功能。

ContextFlow 对用户数据的处理遵循 Chrome Web Store 用户数据政策及 Limited Use 要求。

保留、删除与撤销

  • 你可以在界面中删除批注、导出 Markdown，或停止同步。删除源记录不意味着自动删除所有已导出的文件、备份或第三方留存副本。
  • 卸载扩展会删除扩展自身的浏览器存储，但不会删除本地服务数据库、同步笔记或第三方服务保留的数据。
  • 如需彻底删除本地服务数据，请先停止服务、备份需要保留的记录，再删除你自己的 ContextFlow 数据目录及选定的同步文件。不要删除整个笔记库来清理单个插件。
  • 扩展设置页可清除本机配对码；在项目目录执行 npm run pair -- --revoke <扩展ID> 可立即撤销该扩展在本地服务的授权。重新生成配对码会使旧配对码失效。
  • 旧开发版存放于网页侧的缓存不会自动导入或删除。升级前请先同步或导出旧版离线记录，需要时通过浏览器站点数据设置清理。
