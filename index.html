使用前了解

  • 高亮、批注和 Markdown 导出无需运行本地服务，阅读记录保存在扩展私有存储。
  • AI、笔记同步和本地 agent 需要 Node.js 22.5+、配套本地服务及相应配置。扩展不提供内置免费模型额度。
  • 连接本地服务时，按扩展连接页的提示生成独立配对码；不要把 API key 或配对码提交给维护者。

本地优先不等于所有请求离线处理。AI 功能可能将网页内容、问题及授权读取的笔记发送给你配置的服务。启用前请阅读隐私政策，并了解这些服务的数据处理方式。
