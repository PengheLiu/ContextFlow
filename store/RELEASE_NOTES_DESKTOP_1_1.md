# ContextFlow 1.1.0

桌面客户端适用于 **macOS 13.5+、Apple Silicon（M 系列）**，可从官网下载。Chrome 扩展 1.1.0 单独提交商店审核，以商店实际版本为准；不会替用户卸载或清空已有扩展。

## 使用流程

1. 先安装 Chrome 商店的 ContextFlow，再从官网下载 Mac ARM64 DMG。
2. 将 ContextFlow 放入「应用程序」并打开。应用内置运行环境、自动准备本地服务，不需要安装 Node.js 或运行 npm。
3. 在匹配扩展的「连接与设置」勾选数据说明并点击「连接桌面端」，回桌面弹窗核对后「允许连接」。不需要终端或手工复制配对码。
4. 按需选择模型或 Agent，先测试当前草稿、再保存；笔记位置独立选择并确认。回文章完成实际回答或点击「同步」验证写入。

## 桌面能力

- 状态首页、AI 助手、笔记与设置四个工作区。
- 支持的本地 Agent 与 Obsidian 已登记库的候选发现；发现不等于登录、授权或测试通过。
- 菜单栏状态与重新打开窗口；关闭窗口后仍运行，明确退出才结束服务。
- 模型 / Agent 草稿测试、共享配置与实际回答 / 同步状态反馈。
- 凭据加密保存、本机恢复点、浏览器授权管理及脱敏诊断。
- 官网手动覆盖更新；先让任务结束并退出旧版，保留已有数据，不为更新卸载扩展。
- 普通 HTTP 网页也能安全生成记录编号；修复点击批注无反应的兼容问题。
- 原生授权超时、取消、断开与并发申请有明确边界，迟到的批准不会留下假授权。
- 面板、记录列表与阅读库共用 Markdown / GFM 和公式渲染，保留导出的原始公式文本。

## 安装安全与范围

此包**没有 Developer ID 签名，也未经过 Apple 公证**。macOS 可能阻止首次打开；SHA-256 只验证文件完整性，不证明发布者身份或通过 Apple 安全审核。只从本仓库 Release 或官网链接下载，参阅 [Apple 的安全打开说明](https://support.apple.com/102445)。若系统提示应用损坏或恶意软件，停止安装并反馈，不关闭系统安全保护。

已在 Apple Silicon 本机进行打包、内置服务及隔离生命周期验证；不是所有 Mac 的干净安装证明。Intel Mac、Windows x64 / ARM64 尚未开放下载，不将交叉构建当作实机支持。

统一分发 tag 为 `v1.1.0`，包含 Mac 安装器与同版本 companion、Chrome、网站 ZIP；GitHub 此次标为 prerelease、非 latest。它不覆盖 `v1.0.0`，不表示 Chrome 商店 1.1 已审核或上线。维护者内部仍保留严格签名发行门禁，未签名分发不会伪造签名 / 公证验收；将来正式签名发新版本，不覆盖此 tag。

## 核对下载文件

将 DMG 与同名 `.sha256` 下载到同一目录，再在该目录执行：

```bash
shasum -a 256 -c ContextFlow-1.1.0-mac-arm64.dmg.sha256
```

仅出现 `OK` 表示两份下载文件的摘要一致。不要公开 API key、配对码、配置、阅读备份或私人笔记；反馈时提供版本、系统、复现步骤和脱敏截图即可。
