1.0 已于 2026-10-20 提交 Chrome 商店审核，后台已确认待审核；通过后自动发布，目前尚未上线。此 GitHub Release 不表示已通过 Google 审核。商店当前版本仍可安装。不要卸载已有扩展来更新，以免清除其独立阅读数据。静态网站 ZIP 为冻结时的快照，最新审核进度以官网和本发行页说明为准；不覆盖已发布附件。

## 这一版带来什么

- 原位图文批注与侧栏共享记录；新的阅读工作台按原文分组、搜索与筛选，长答案收起、取消 / 重试、最近五个历史回答及页面内删除撤销。
- 「我的阅读库」跨文章搜索与预览；单篇含图 Markdown、完整阅读 JSON 备份与校验后补充恢复，不覆盖已有或已删除记录，不重启 AI。
- LLM / Agent 分别测试，模型列表有数量与失败反馈，欢迎页和阅读设置共享带时间的连接测试结果。测试草稿不保存配置，保存需明确点击。
- 仅主动生成才调用 AI；取消向上游传播；排队任务保持提交时的模型、凭据与权限，不因别的页面改配置而切换目标。
- 帮助与诊断、可预览的脱敏报告、键盘调宽 / 移动 / 缩放、焦点恢复、窄屏 / 深色 / 减少动态效果。
- 重写产品文档、升级说明并重拍真实截图。未新增浏览器权限、遥测或云账号。

## 选择正确的文件

- **商店安装用户：** 等待同一条目更新；AI / 笔记同步需要与实际扩展版本匹配的 `contextflow-companion-1.0.0.zip`。不要在 0.3.2 连接页误选新版本服务包；优先使用页面生成的匹配链接。
- **手动测试：** `contextflow-chrome-1.0.0.zip` 是解压加载的无凭据备用扩展包，不包含本地服务。不要与正式版同时启用；手动扩展 ID 与数据空间不同，按其选项页独立配对。
- `contextflow-store-site-1.0.0.zip` 为静态官网文件，不是服务。
- `.sha256` 是校验文件。不要将 Source code 当成预先配置好的服务。

安装与升级：[完整指南](https://github.com/PengheLiu/ContextFlow/blob/main/docs/GETTING_STARTED.md)。升级本地服务保留原配置与数据，先停止旧服务，不重复生成配对码。

## 已验证与边界

完整自动测试、全新 production 依赖 / 配对 / 撤销、macOS 隔离 Chromium 端到端、真实扩展截图与导出均通过。模型及 CLI 使用可控模拟服务，未调用私人付费账号。生产依赖安全检查未发现已知漏洞（检查时点）。

中文界面为主；完整 JSON 单份上限 32 MB、未加密；无云同步。翻译始终需要 LLM，Agent 仅用于解释与速览。Windows / Linux 独立实机、不同真实上游与新用户研究仍需持续验证。[详细范围和限制](https://github.com/PengheLiu/ContextFlow/blob/main/docs/RELEASE_1_0.md) · [跨入口审查记录](https://github.com/PengheLiu/ContextFlow/blob/main/docs/RELEASE_AUDIT_1_0.md)。
