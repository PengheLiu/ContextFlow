## 详细说明

读到有启发的地方，就地记下你的想法。

ContextFlow 让你在网页原文旁写批注、粘贴截图，把原文、想法与来源一起导出 Markdown，带回自己的笔记。基础功能无需注册、Node.js、API key 或本地服务。

第一次使用：打开普通文章并刷新，选一句原文点击「批注」，写下想法，再到右侧栏底部点「下载」。安装后可用练习文章完成这条路径：https://pengheliu.github.io/ContextFlow/demo.html 。

按需要逐步开启：

- 离线高亮与批注：阅读记录保存在扩展私有存储，可导出 Markdown。
- 我的阅读库：跨文章搜索、按内容类型筛选，预览自己的理解，下载带图片的单篇 Markdown。
- 备份与恢复：导出有效记录、历史回答和引用图片，校验后补充恢复，不覆盖已有内容或重启 AI。JSON 未加密，单份上限 32 MB，请妥善保管。
- 解释与文章速览：使用你自己的 LLM 或本地 Agent；翻译需单独配齐 LLM。扩展不提供内置免费模型额度。
- 笔记同步：通过本地服务同步至 Obsidian、Markdown 目录或已配置的思源服务。
- 个人上下文：明确授权笔记目录后，让本地 agent 在阅读时参考已有知识。
- 站点控制：可以停用指定页面或站点，并随时恢复。
- 可靠性与控制：长回答折叠、取消 / 重试、历史答案、删除撤销和明确保存反馈；获取模型、LLM / Agent 测试与保存配置分开，测试状态跨入口保留。
- 帮助与诊断：预览与复制脱敏版本、连接和存储计数，不上传报告，不包含文章、网址或密钥，不触发 AI。

安装前请了解：

1. 高亮、批注和 Markdown 导出不要求运行本地服务。
2. AI、笔记同步和本地 agent 功能需要 Node.js 22.13+、本地 ContextFlow 服务及相应配置。macOS 提供常驻服务脚本，其他系统的自动安装尚未验证。
3. 扩展安装后，在连接页面按提示生成独立配对码，不需要将 API key 交给扩展发布者。
4. 本地优先不代表所有请求离线处理。AI 功能可能将网页内容、问题及授权读取的笔记发送至你配置的第三方服务；相关费用和隐私安排由你与服务提供方确定。
5. 暂不支持 Chrome 内部页面、Chrome Web Store、内置 PDF 阅读器或本地文件页面。

## Single purpose

帮助用户对正在阅读的网页进行高亮批注、解释和总结，并将阅读记录保存在用户自己的笔记系统中。

## 权限理由

- `storage`：保存站点偏好和本机配对凭证。凭证仅对受信任的扩展上下文开放，不使用 Chrome 同步存储；阅读事实库位于扩展自己的 IndexedDB。
- `http://127.0.0.1:7317/*`：连接用户自己运行的本地 ContextFlow 服务，用于验证配对、AI 请求及笔记同步。不是开发者远程采集端点。
- HTTP/HTTPS content script：在用户阅读的普通网页恢复已有标注、识别选区并呈现阅读面板。可在产品内停用页面或站点；不会请求浏览器 history、cookies 或 webRequest 权限。
- 远程代码：不在扩展中加载或执行远程 JavaScript。AI 结果作为内容显示；本地服务及 agent 的用途和依赖在说明中公开。

## 隐私申报核对

不可勾选“不处理任何用户数据”。应根据后台分类口径逐项确认：

- 网站内容：网页正文、选区、图片、笔记片段、批注及问答。
- 浏览活动相关信息：当前功能所处理页面的 URL 和标题，不等同于申请浏览器历史记录权限。
- 认证信息：本机配对凭证，以及用户在配置本地服务时填写的模型或笔记服务凭证。
- 不以广告、信用评估或与阅读功能无关的目的使用用户数据。

已部署的隐私政策：https://pengheliu.github.io/ContextFlow/privacy.html 。源文件为 `store/privacy.html`，后续修改需同步部署与申报。
