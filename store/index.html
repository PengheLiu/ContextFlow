下载 Chrome 试用版已安装？打开练习文章 →

Chrome 商店版 v0.3.1 正在审核。当前通过解压加载试用；安装步骤见下方。基础批注与导出无需账号、Node.js 或 API key。

先安装，再完成第一条批注

  1. 01

    下载并解压 Chrome 包

    在发行页 Assets 中选择 contextflow-chrome-0.3.1.zip。首次不用下载 companion 或 Source code。

  2. 02

    加载扩展，刷新文章

    打开 chrome://extensions，启用开发者模式，点击「加载已解压的扩展程序」，选择含 manifest.json 的文件夹。

  3. 03

    写一条批注并导出

    打开练习文章，选中文字后点「批注」。右侧栏里点「下载」，得到带来源的 Markdown。刷新后记录会恢复。

查看完整安装与使用指南 ↗

练习文章是用于实际操作的普通网页，需要先安装扩展。Chrome 商店页、内部页面和内置 PDF 阅读器不能使用批注。

首次安装后先刷新已经打开的文章；v0.3.1 的连接页可以暂时关闭，直接使用批注。

按你的阅读需要，再多走一步

想自动写入 Obsidian 或 Markdown？

下载发行页的 companion 本地服务包，安装 Node.js 22.5+，按扩展连接页配对，再选择笔记保存位置。只同步笔记，不要求配置 AI。

开启自动同步 →

想解释原文、翻译或生成速览？

连接本地服务后，配置自己的模型和 API key。使用费用由模型服务决定，扩展不提供内置额度。进一步使用本地 agent 时，可以明确授权个人笔记目录。

AI 请求可能把网页、问题和授权笔记发给你配置的服务；本地优先不代表所有请求离线处理。

记录属于你，也需要你备份

扩展记录保存在浏览器的扩展私有空间；导出的文件可以在其他编辑器和笔记软件继续使用。建议定期导出或同步，卸载扩展会清除扩展内数据。
