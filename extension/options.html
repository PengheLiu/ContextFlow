1 下载并启动本地服务

先安装 Node.js（22.5 或更高版本），再下载 发行页中的 contextflow-companion 服务包，解压到固定文件夹。

在解压后的文件夹打开终端，运行：

npm ci --omit=dev
npm run server

终端出现 127.0.0.1:7317 即已启动；保持这个终端运行。怎样打开终端？看分步指南 ↗

使用 AI：在同一「配置」页选择模型并填入自己的 API key，再选一小段原文点击「解释」验证。个人笔记和 agent 可以以后再设置。

连接不上？先检查这几件事
  • 「npm 不是内部命令」或「command not found」：安装 Node.js 后重新打开终端。
  • 无法找到 package.json：终端需进入解压后有 package.json 的文件夹。
  • 服务未连接：保持运行服务的终端打开，再点「检查本地服务连接」。
  • 配对失效：重新复制上方命令生成配对码，旧码会同时失效。
