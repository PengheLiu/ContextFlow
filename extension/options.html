连接你自己的知识库

高亮与批注保存在扩展私有空间。需要 AI、笔记同步或本地 agent 时，再连接你自己的本地服务。

1. 启动本地服务

需要 Node.js 22.5 或更高版本。在项目目录安装依赖后启动服务：

npm ci
npm run server

macOS 也可运行 npm run service 配置常驻服务。Windows / Linux 的常驻安装尚未验证，请先使用前台服务。连接地址固定为 127.0.0.1:7317。

隐私与旧版数据

      
浏览器缓存位于扩展私有 IndexedDB，偏好及配对凭证位于扩展存储；不新增遥测、广告或开发者云端同步。AI 及笔记同步仅连接你配置的服务。

      
卸载扩展会清除其浏览器数据，但不会删除本地服务数据库或笔记目录。删除本地数据前请先导出并备份。

      
从旧开发版升级前，请先同步或导出未同步批注；新版不自动信任或导入普通网页存储中的旧缓存，旧数据不会被自动删除。
