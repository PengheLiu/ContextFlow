# ContextFlow 1.1.2：DSH 连接测试与升级兼容修复

这是桌面客户端与配套服务的修复更新，与 Chrome 商店已发布的 1.1.1 扩展兼容。本次不提交新的 Chrome 商店版本。

## 修复内容

- DeepSeek Harness 桌面版的连接测试不再按版本白名单禁用。检测到桌面安装后可尝试测试，由独立进程检查实际模型接口、只读凭据接口与禁用工具的隔离能力，再发送固定短消息。
- 升级 CLI、桌面主程序或内部 `app.asar` 后，检测缓存和旧连接测试结果立即失效。即使启动脚本未变化，也不会继续显示旧版已通过。
- 接口缺失或不兼容时返回明确提示，不加载用户插件，不自动切换 Agent，也不将连接测试提升为完整工具权限。
- 桌面发现列表、设置页提示与测试按钮状态一致；用户可先测试当前选择，通过后再保存。

连接测试只验证登录与模型回应。实际阅读所用的完整 Agent 会话协议仍单独校验；接口发生实质变化时可能仍需适配，不能保证所有未来版本的全部能力自动可用。

## 安装与更新

从[官网下载页](https://pengheliu.github.io/ContextFlow/download.html)获取 Mac Apple Silicon DMG 与对应 SHA-256。需要 macOS 13.5 或更高版本；Intel Mac 与 Windows 安装包尚未开放下载。

正常退出旧应用后，将新版放入「应用程序」覆盖安装，再打开。已保存配置、阅读记录与浏览器授权保留；重启前请先处理未保存草稿以及正在执行或排队的任务。无需卸载 Chrome 扩展。

此独立安装包的签名与系统限制沿用官网下载说明，不将内容完整性校验当作 Developer ID 签名或 Apple 公证。

版本升级、缓存失效、接口变化、隔离握手、固定短消息、凭据写锁、取消与超时均有回归覆盖。已安装的 DSH `0.2.1-rc.5` 使用临时配置和本地模拟模型验证，未调用个人付费模型或读取私人笔记。Mac ARM64 安装包另行核对内置运行时、文件摘要与包完整性；这些结果不代表其他系统实机验收或 Chrome 商店审核。
