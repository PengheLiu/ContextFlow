# 能力、兼容性与数据边界

[开始使用](./GETTING_STARTED.md) · [客户端下载与系统要求](https://pengheliu.github.io/ContextFlow/download.html) · [返回首页](../README.md)

这里描述 ContextFlow 1.1 的完整产品流程，不代表所有分发渠道已经提供这一版本。实际可安装版本以 Chrome 商店为准；桌面连接还需满足下载页的扩展版本与系统要求。没有桌面端也可以完成基础阅读，不用卸载、清空数据或购买模型来解锁批注。

## 按需要开启能力

| 能力 | 需要准备 | 完成标志 |
| --- | --- | --- |
| 高亮、原位图文批注、阅读库 | 仅安装扩展，在普通网页刷新后使用 | 原位与侧栏显示同一条记录，刷新后仍在 |
| Markdown 导出、JSON 备份与补充恢复 | 仅安装扩展，无需账号或服务 | 文件实际下载；JSON 经校验、预览和确认后才写入 |
| 解释、追问、文章速览 | 连接桌面端，配置自己的 LLM 或支持的本地 Agent | 当前配置完成真实回答；仅发现程序或测试成功不等于真实使用成功 |
| 翻译 | 连接桌面端并配置 LLM | 得到翻译结果；只配置 Agent 不足以使用翻译 |
| 参考个人笔记回答 | 支持相应读取模式的 Agent，单独授权读取目录 | 对测试笔记得到可核对的回答；同步目的地不自动授予读取权限 |
| 同步到 Markdown、Obsidian 或思源 | 连接桌面端，保存并确认笔记目的地 | 在网页点击「同步」，到实际位置核对文件或文档 |

LLM 使用自己的 OpenAI 兼容接口或 Anthropic 配置。兼容网关的模型列表、推理能力、额度和隐私安排以提供方为准；不能获取模型列表时可以手填。连接测试只发送固定短消息，可能产生少量费用，不发送文章或笔记，也不自动保存草稿。Agent 安装、登录和对应版本的权限支持需分别验证，不为通过测试自动开启 Full。

## 网页与系统兼容

- 基础阅读支持桌面 Chrome / Chromium 111+ 的普通 HTTP/HTTPS 网页。Chrome 内部页、扩展商店、内置 PDF 阅读器和本地文件页不支持；论文可优先使用对应 HTML 正文。
- 桌面连接按 Google Chrome 验证，不把其他 Chromium 浏览器的基础阅读可用等同于桌面桥接已适配。安装或更新后，已打开的文章需要刷新。
- 桌面包的操作系统、芯片架构、签名和真实开放状态以[下载页](https://pengheliu.github.io/ContextFlow/download.html)为准。当前 Mac Apple Silicon 包要求 macOS 13.5+；未开放的平台不提供可用安装包承诺。
- 当前界面主要为中文。英文 README 说明产品，不代表已有完整英文界面。
- 网页结构变化可能影响高亮恢复和原文定位；已有阅读记录仍可在阅读库查看与导出。产品不保证任意网页都能准确提取全文。

## 内容格式与图片

解释面板、侧栏和阅读库共用 Markdown / GFM 与数学公式渲染。支持范围、安全边界及不支持的方言见 [Markdown 兼容说明](./MARKDOWN.md)。无效公式保留原文，不执行模型输出中的脚本或任意 HTML；超长预览不截断保存与导出内容。

单张本地图片限 8 MB，支持 PNG、JPEG、WebP。粘贴的是图片数据，不只是外部图片网址；图片未成功保存时不会假装导出了完整文件。导出只包含扩展中本地可用的引用图片，未缓存的图片需要先在原文章加载。

## 备份不是云同步

完整阅读 JSON 包含此扩展中已保存的有效记录、最近保留的历史回答及引用图片；不包含已删除记录、原网页全文、模型配置、密钥、配对凭据或只在本地服务中的内容。文件可读且未加密，请保存在私人位置。

单份 JSON 的安全上限为 **32 MB**，导出和导入使用同一字节限制，不另设记录数或图片数门槛。旧版已导出的有效文件在此限制内也可恢复。超限明确失败，不截断、不删除原记录；按篇下载 Markdown 可以带走内容，但 Markdown 不是可直接导回的 JSON 备份。当前不承诺自动分卷或跨卷恢复。

恢复先校验全部记录和图片，展示预计新增内容，明确确认后在一个本地事务中补充。已有记录与 tombstone 优先，不用旧备份覆盖当前编辑或复活已删除记录；写入失败整体回滚，原备份可保留重试。不恢复模型作业、CLI 会话或自动写入外部笔记，未完成的 AI 请求需要手动重试。

桌面「本机恢复点」保护本电脑原系统账号的服务数据和配置，不是浏览器完整备份、跨电脑迁移或整个笔记库的撤销工具。浏览器阅读记录、桌面服务数据与已同步的外部笔记是不同副本，需要分别保护。

## 权限与恢复

浏览器实例分别授权，桌面端可独立撤销；关闭桌面窗口不退出服务，选择「退出 ContextFlow」才会停止。本地优先不等于 AI 完全离线：网页内容、问题与授权笔记可能发送到自己配置的第三方服务。

新 Agent 配置从受限能力开始；隔离边界依赖具体 Agent 与版本。Full 可能包含文件写入、命令、网络或 MCP，应明确理解风险后单独确认，网页和笔记内容仍视为不可信。

卸载扩展会清除其浏览器记录，不会删除桌面数据或已同步笔记。更新优先采用同一条目及匹配安装包的覆盖更新，不通过卸载、清空配置或重新配对修复所有问题。[安装与排障](./GETTING_STARTED.md) · [隐私政策](https://pengheliu.github.io/ContextFlow/privacy.html)
