# 1.0 跨入口发布审查

日期：2026-10-20。目标是降低重复送审风险，不承诺 Google 必然通过或所有环境零缺陷。

## 已发现并修正

| 问题 | 修正与验证 |
| --- | --- |
| 官网、GitHub 的旧版截图 / 说明与新界面不一致 | 重拍 1.0 原位批注、阅读库；安装入口附近与 README 顶部明确区分商店 0.3.2 和待提交 1.0 |

| 开发构建日志仍引导手改 allowedOrigins，公开 userscript 文档残留旧版本 | 构建日志改为同一套独立配对流程；明确独立脚本不是 Chrome 扩展 / companion，版本由构建填写 |
| 文件页面范围说明含糊 | 统一说明不支持本地文件 / 内置 PDF / Chrome 内部和商店页面，不暗示授予文件权限后就能使用 |
| 排障和无障碍闭环不足 | 补齐白名单脱敏诊断、私有只读计数、键盘调宽与浮层移动 / 缩放、焦点恢复、编辑器可访问名称 |
| 排队期间跨页保存配置可能改变既有任务的模型 / 凭据 / Agent 权限 | 翻译、解释、速览捕获提交时的配置快照；HTTP 集成测试确认更改模型与密钥不影响排队任务，只影响新请求 |

## 代码、包和文案核对

- 固定原扩展 ID；版本由 package.json 同步 manifest / 安装页服务下载 / companion 锁文件；服务单独升级。
- 权限仍只有 `storage`、本机 `127.0.0.1:7317` 和原 HTTP(S) content script 匹配。无新增 history / cookies / webRequest / tabs 权限，无远程代码。
- 原文旁与侧栏共享事件 ID；导出 / 同步 / 备份先等待编辑与图片落盘。恢复仅补缺失记录、不复活删除记录，不重启 AI。
- 默认行为、隐私正文和说明统一：打开 / 恢复 / 诊断不调用 AI；主动测试发送固定消息，不保存配置；正文仅在主动 AI 使用中提供。已在运行的任务恢复只查原 job 状态，不创建新计费任务。
- 数据分别存放：扩展私有阅读库、电脑服务配置 / 数据库、用户自己的笔记副本。JSON 可读未加密，32 MB 上限，不含密钥或原网页全文；不承诺备份含服务端独有记录。
- `test/release-consistency.test.mjs` 新增跨入口门禁：版本、ID、安装命令、本地文档链接、截图、能力前提、备份边界和 Markdown 分类顺序。
- 商店包 / companion 测试增加隐私正文和资源存在性检查。完整测试、生产依赖安装、隔离 Chrome 端到端通过；生产依赖安全检查无已知漏洞。

- 已读取公开商店：当前版本 **0.3.2**；隐私链接指向正式 Pages，支持链接指向 GitHub Issues。公开页面未展示产品官网首页入口，提交 1.0 时须核对后台首页字段。
- GitHub 默认分支 main、About 官网正确；审查时最新公开发行仍为 v0.3.2。1.0 源码、包和官网发布后需再次验证实际公开内容，不能把本地产物当线上证明。
- 本地官网桌面与 390px 窄屏无横向溢出，FAQ 可展开，安装主按钮指向正式商店，演示明确需要安装扩展。官网静态页面无脚本 / iframe / 表单 / 追踪。
- **商店登录待维护者完成。** 目前不能检查或保存私有后台的当前草稿、权限申报、截图、首页或审核指引，也尚未提交 1.0。不得把这些写成已通过。
- 提交时仍须依次检查：上传包版本 / SHA、两张真实 1280×800 截图、商店说明、官网 / 支持 / 隐私、数据类别与 Limited Use、审核人员安装指南，最后确认后台明确显示已提交。
