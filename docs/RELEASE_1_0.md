## 1.0 的完整阅读路径

安装扩展 → 原位高亮 / 图文批注 → 阅读工作台整理 → 阅读库找回 → Markdown 导出或 JSON 备份。基础路径不需要注册、本地服务或模型。

按需连接本地服务后，可主动使用解释、翻译、速览及笔记同步。LLM 与 Agent 分别检测、测试，欢迎页和阅读设置共享实际连接的验证记录；获取模型和测试草稿不会保存配置。AI 不会因为打开侧栏、刷新或恢复备份自动调用。

- 原位与侧栏编辑同一条记录；失败保留草稿，保存、同步和恢复都有明确结果。
- 按原文位置合并展示，全文搜索 / 类型筛选；长答案折叠、取消、重试、最近五个历史答案及页面内删除撤销。
- 跨文章检索、单篇含图 Markdown、完整阅读 JSON、校验预览和原子补充恢复。不会覆盖已有记录或复活 tombstone。
- 诊断只读连接与存储，报告严格白名单，可先预览再复制；不收集遥测或上传报告。
- 键盘切换阅读标签、调整侧栏宽度、移动 / 缩放解释浮层，Esc 关闭并恢复焦点。收起侧栏立即移出焦点顺序，尊重减少动态效果，适配窄窗口 / 深色 / 强制颜色。
- 不新增浏览器权限，不执行远程代码；配对码仅扩展可信上下文可读，阅读库批量接口不向网页开放。

## 明确的能力边界

1. 界面以简体中文为主，英文 README 不代表已有完整英文 UI。
2. 每份 JSON 备份上限 32 MB，单张图片上限 8 MB。超限拒绝而不截断；可按文章导出 Markdown。大备份分卷 / 流式格式不在 1.0 中。备份未加密，卸载前务必导出。
3. 不包含云账号同步；浏览器数据、配套服务数据和笔记软件副本是不同存储。停止连接或卸载不删除已导出的文件。
4. 模型与 Agent 需要自己的账号或服务，费用另计。固定短消息测试通过不保证笔记检索、完整权限或未来请求总能成功；实际外部模型 / CLI / 思源账号需按自己的配置验证。
5. macOS 实机与隔离 Chromium 已验证；Windows / Linux 文档提供前台服务命令，未完成独立全新机器验收，不承诺自动常驻安装器。
6. Chrome 内部页面、商店、内置 PDF 阅读器和文件页面不支持注入；网页改版可能使原文定位失效，阅读记录仍可导出。
7. 本轮没有进行 5–8 位独立新用户研究；不宣称已经达到某个评分或「所有环境零问题」。

## 升级与回退

商店版等待同一条目自动更新，不卸载。更新前建议「我的阅读库 → 下载完整备份」；旧版可先导出 Markdown 或同步。

本地服务单独升级：下载与实际扩展版本匹配的 companion，保留现有 `CONTEXTFLOW_DIR` / `~/.contextflow`，停止旧服务，更新代码与生产依赖后再启动。不重新生成配对码。macOS 若常驻配置指向旧目录，先在新目录安装常驻服务；不要同时启动两个进程。

回退只换扩展 / 服务代码，不删除数据目录；旧版不具备新界面和备份入口。先保留 1.0 JSON 和 Markdown，再按具体问题选择回退。已公开版本的 GitHub 附件和 tag 不覆盖。
