# Markdown 预览兼容范围

解释弹窗、侧栏阅读记录（含折叠摘要与历史答案）、速览和阅读库共用一套渲染器。显示格式不改写保存的 Markdown；复制、下载、同步仍使用原文，不导出渲染后的 HTML。

## 已支持

- CommonMark：六级标题、Setext 标题、段落与换行、粗体/斜体及嵌套强调、转义与字符实体、分隔线、嵌套列表和引用、引用式链接、行内代码、反引号/波浪线围栏、缩进代码。
- 常用 GitHub 风格扩展：表格及列对齐、删除线、只读任务列表、HTTP(S) 自动链接、NOTE/TIP/IMPORTANT/WARNING/CAUTION 提示块。
- 脚注：命名/行内脚注、重复引用、点击定位与返回；各条记录的引用目标彼此隔离。
- LaTeX 数学：`$…$`、`$$…$$`、`\(…\)`、`\[…\]` 与 `math` 代码围栏；支持 KaTeX 可识别的分数、根号、积分、求和、上下标、矩阵、分段函数、多行对齐等。表格、列表与引用中的公式同样可用。

公式由随扩展打包的 KaTeX 解析，以浏览器原生 MathML 显示。沿用桌面 Chrome/Chromium 111+ 的产品基线，无 CDN、远程脚本、字体下载或新增扩展权限；宽公式和表格在容器内部横向滚动。

## 安全与明确边界

- 模型输出不可信：原始 HTML、远程图片和非 HTTP(S) 链接不生成活动内容。用户粘贴的本地图片仍由现有附件流程展示，和 Markdown 外链图片是两条独立路径。
- 数学渲染禁用可信命令，不允许公式创建外链、加载图片或注入 HTML 属性；宏按单个公式隔离，并限制公式长度、数量、宏展开次数与尺寸。
- 无效或不支持的公式保留原文，不影响后续正文。代码区域不渲染公式；货币与转义美元不当成数学。
- 不执行 Mermaid/PlantUML、任意 HTML、MDX/JSX 或第三方 Markdown 插件代码；对应围栏保留为代码。并非所有 Markdown 方言、LaTeX 宏包或自定义命令都兼容。
- 极长回答预览最多处理 20 万字符，原始保存与导出内容不截断。

## 验证

`npm test` 覆盖公式与 Markdown 格式、安全输入、渲染预算、弹窗/列表/速览/阅读库及导出保真。运行 `node tools/preview-markdown.mjs`，打开输出的本机地址即可检查真实组件的合成样文。测试页禁止网络连接、远程图片和字体请求，不连接用户模型或个人笔记。
