# 体验优化进度

> 当前汇总：以上阶段开发成果已纳入 1.0.0，另补齐脱敏诊断、万条性能基准、键盘调宽 / 移动 / 缩放与焦点恢复。历史段落中的「仅本地 0.3.3」为当时记录；最新范围、验证和商店提交状态以 [1.0 发行说明](./RELEASE_1_0.md)为准。

## 第一阶段：操作可预期与设置分层

本轮改动属于本地开发版 0.3.3，尚未提交 GitHub 或 Chrome 商店。公开商店仍为 0.3.2。

- 打开、恢复、重新连接侧栏只读取已有速览或显示生成入口，不上传正文、不自动调用 AI。主动生成和重新生成才触发请求。
- 获取模型与测试连接使用临时草稿，不写 `/config`；选择模型也只修改表单。所有配置均由「保存更改」明确提交。空密钥沿用已保存值，但更换服务地址或接口类型后必须重新填写密钥，防止把旧密钥发送到新地址。
- 旧服务按实际能力检测，显示运行版本和更新说明。不要求重新配对，不以隐式保存兼容旧测试接口。
- 设置分为可展开的 AI、解释方式、笔记同步和站点权限章节。配置完整时先展示摘要；新用户默认展开尚未配齐的 AI 连接。收起再打开不会丢掉未保存草稿。
- 获取模型保留当前模型，报告去重后的数量。结果保留在操作附近并显示一次 Toast，不再在底栏重复同一消息；底栏负责未保存状态。
- 原位批注等浏览器持久化完成才显示保存成功。「完成」等待落盘；失败保留编辑器与草稿，支持原文不变时重试。
- 浏览器保存、侧栏镜像和笔记软件同步使用不同措辞。笔记同步防重复提交，结果持续展示后端及返回的目标路径。
- 阅读 Tab 补齐方向键、Home/End 与焦点顺序；原文定位支持 Enter/空格。
- 更正 README、安装指南与官网源文件的公开版本信息。不包含线上部署。

不改变事件协议、批注双向同步或 Markdown 的分类与排序。

## 阅读工作台（本地开发版已实现）

- 三个清晰入口：阅读记录、文章速览、我的笔记。机器概述与个人理解不再混在一个标签中。
- 阅读记录按原文位置排列；相同且定位成功的选区合并展示一次引文，批注、解释、翻译各自保留记录 ID。重复文字在不同位置、重叠选区和失锚记录不合并。
- 支持全部 / 批注 / 解释 / 翻译筛选和文章内全文搜索，覆盖原文、问题、回答与个人补充，显示匹配数量及空结果提示。
- 列表按 ID 增量更新。后台进度、切换筛选和切换标签不销毁编辑器，保留输入、图片粘贴、光标和回答展开状态。
- 长回答默认展示摘要预览，可展开全文。原位追问、复制、重新生成、取消与删除均在回答之前，不需要滚动长答案才能操作。
- 重新生成期间保留旧答案；失败或取消不清空。成功后保留最近五个不同的历史答案，个人补充不变；Markdown 仍只导出当前答案，不混入历史版本。
- 解释与速览可独立取消。新服务将 LLM 解释 / 速览与 Agent 都放入可取消队列，取消向模型请求或本地子进程传递 AbortSignal；旧服务仍兼容同步响应，无法保证旧服务停止上游。供应商已经产生的费用不能撤回。
- 取消后允许立即重新生成；旧请求晚到或结束清理不能覆盖新请求。取消记录刷新后不会自动重试或计费。
- 删除提供当前页面会话内最近 20 次撤销。恢复原 ID、锚点、批注草稿、补充与图片引用，以更高 mutation 时间抵抗旧 tombstone；恢复进行中的记录不会自动重启 AI。
- 原位编辑器关闭后将键盘焦点交回原入口（仍存在时），避免跳到页面开头。
- 扩展图标无法打开侧栏时进入专门的阅读帮助，说明刷新、受限页面、PDF HTML 替代与网站权限，不再暗示必须配置 AI 或重新配对。不新增权限，也不读取或传递当前网址。
- 窄窗口自动使用浮层并约束到可见视口，不改变桌面停靠偏好。导出与同步先等待编辑落盘，图片未保存完成时明确提示；同步会等待正在发送的自动保存确认，避免最后一句遗漏。
- 设置读取期间显示加载状态，合并重复请求，配置就绪后再开放表单；避免异步初始化把刚展开的章节或新输入覆盖。

验证补充：`test/reading-workbench.test.mjs` 覆盖分组边界、输入 DOM 与光标稳定、历史版本、离线撤销、取消信号与并发槽位；隔离 Chrome 测试覆盖扩展 → 本地服务 → 模拟模型的真实取消及恢复链路。Tabbit 用于检查真实侧栏组件的布局、筛选、搜索与状态。

## Agent 验证与设置状态（本地开发版已实现）

- Agent 使用「检测安装 → 选择 → 测试连接」流程。安装列表显示数量、版本和未安装状态，不把程序存在当作已经登录或能回答；检测不会偷偷替换已选择但不可用的 Agent。
- `POST /agents/test` 只接受 Agent ID，以异步队列运行固定短消息，不接受自定义任务或权限，不保存配置、不传正文或笔记、不授权笔记目录。强制使用 Safe、新会话、单轮与 45 秒执行上限。当前仅支持已有受限适配的 Claude Code / Codex；其他 CLI 不会自动获得 Full 权限。
- 安装、实际回答和测试范围分开呈现。成功、登录失败、异常退出、超时、旧服务能力不足、取消均有原位反馈；支持取消后立即重试。检测发现卸载或版本/路径变化会使旧测试结果失效。
- 所有真实调用都需用户主动点测试，可能消耗自身 Agent 额度。自动检测只探测程序与版本。测试本身通过不代表笔记读取、Full 权限或未来模型调用始终可用。
- 设置章节改为有边界的卡片，标题持续显示配置摘要、验证状态、明确的「展开 / 收起」和方向箭头。初次加载按完整性选择默认状态；之后保留用户展开选择，多个章节可以对照，不自动折叠正在看的章节。
- 仅内容区做 180–200ms 高度动画，标题不移动、不整块淡入淡出；连续点击从当前位置反向，收起前将焦点交回标题。尊重系统减少动态效果，保留表单节点、草稿和保存状态。扩展连接页使用同一套折叠机制，不再把加号旋转成关闭叉号。
- 验证新增 Agent 连接、旧服务能力预检、取消竞态、动画反向与焦点测试。隔离 Chrome 使用临时模拟 CLI 子进程验证真实启动、认证失败、中止和配置不变；未调用用户真实 Agent 账号或付费服务。Tabbit 检查真实设置组件的宽窄布局、反馈与折叠往返。

## 跨入口测试记录与回答方式说明（本地开发版已实现）

- 欢迎页与阅读页从本地服务读取同一份连接测试记录，显示上次测试时间。关闭页面、刷新、重启服务不丢失；读取记录不会再次调用模型或 Agent。
- 记录绑定实际模型接口、规范化地址、模型与密钥，Agent 绑定 CLI 路径、版本和该 Agent 的服务环境配置。更换连接不沿用别的连接的结果；新的测试失败覆盖旧成功，取消不伪造成功，迟到请求不覆盖新结果。
- 测试仍不保存配置：未保存草稿不会影响其他页面。显式保存后，新页面能恢复该配置已有的测试结果。服务端单独持久化至 `connection-checks.json`（最多 64 条），只存服务密钥派生的 HMAC、结果与时间，不存明文连接、密钥或文章。旧服务明确提示更新，不声称支持跨页记录。
- 回答方式下拉精简为「LLM / 本地 Agent」，旁边的问号可点击或键盘展开原位说明，Esc 收起并交回焦点。说明区分上下文回答、授权笔记和工具、Safe / Full 权限、翻译始终使用 LLM，以及连接测试的范围。不把速度承诺写死为几秒。
- 验证包括服务重启、密钥/接口变化失效、失败与取消竞态；隔离 Chrome 覆盖欢迎页测试保存 → 阅读设置恢复 → 刷新 → 重启，确认恢复期间零 AI 调用。

## 阅读库与数据可迁移性（本地开发版已实现）

本轮优先补齐长期使用路径，不新增账号、遥测或浏览器权限。参考 [Readwise 的文章与全库导出](https://docs.readwise.io/reader/docs/faqs/exporting)、[Raindrop 的备份与迁移](https://help.raindrop.io/export)确定能力基线，不以功能数量或主观观感宣称已达到实际商店评分。

- 侧栏与扩展选项页均提供「我的阅读库」，与首次使用和连接配置分开。扩展自己的页面跨文章检索标题、网址、原文、问题与个人笔记，支持内容类型筛选、排序、20 条分页、空态与只读预览；可直接回原文、下载包含图片的单篇 Markdown。
- 完整阅读备份包含扩展内有效记录、历史回答与引用图片，不包含配置、密钥、全文缓存、删除记录或仅存服务端的数据。纯离线可用；图片丢失或哈希不匹配时拒绝生成不完整文件。JSON 可读且未加密，单份上限 32 MB，超限不截断、不删除源数据。
- 导出和确认恢复前，受信任的扩展页请求所有已打开的阅读页面提交编辑。明确保存失败或无法确认时停止，普通无插件标签不会阻塞。
- 恢复采用「选文件 → 校验完整性 → 预览数量与预计新增 → 明确确认」流程。仅补充缺失实体，现有记录、tombstone 及其被删除的父批注不复活；记录、图片、待保存操作在一个 IndexedDB 事务内提交，失败整体回滚。
- 未完成的 AI 请求恢复为已中止、需手动重试，丢弃旧 job/session 标识，不自动付费。恢复只保存阅读数据；打开文章时按既有规则保存到本地服务，不自动写入笔记软件。
- 全库读取和恢复仅由受信任扩展页直接访问，不加入网页侧 RPC 白名单。预览不解释原始 HTML，不加载远程图片，仅解析私有图片 Blob；原文只允许不含用户名密码的 HTTP(S) 地址。图片 URL 随预览切换释放。
- 隔离 Chrome 覆盖真实扩展入口、Markdown/JSON 下载、图片预览、预览取消/确认恢复、重复导入、损坏文件拒绝、窄屏与零 AI 调用。单元测试覆盖原子回滚、内容保留、删除边界、密钥排除和恶意内容。
