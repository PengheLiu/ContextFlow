# ContextFlow 1.1.5

- DeepSeek Harness 桌面版升级后，ContextFlow 会检查本机阅读会话接口。接口兼容时，解释、速览和续问可继续使用。已用本机 DSH `0.2.2-rc.3` 和模拟模型验证流式回答、续问、取消与官方账号连接。
- 桌面左下角和扩展阅读面板右上角各保留一个更新入口。发现新版本时入口高亮，检查失败时可从原处重试。

使用 DSH 时，先退出 ContextFlow，再从[官网下载页](https://pengheliu.github.io/ContextFlow/download.html)下载并覆盖安装桌面端。应用会继续使用现有配置、阅读记录和浏览器授权。Apple Silicon Mac 安装包要求 macOS 13.5 或更高版本。安装包未使用 Developer ID 签名、未通过 Apple 公证。

桌面版独立分发。扩展更新由 [Chrome 商店](https://chromewebstore.google.com/detail/contextflow/aemncphfnlpbhlddifhohpgegejjejfm)审核和分发。
